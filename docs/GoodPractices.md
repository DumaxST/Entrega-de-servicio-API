
# Good Practices

- Use clear and descriptive names for files and directories.
- Organize files by feature or module to enhance maintainability.
- Follow consistent coding conventions and styles across the project.
- Document code with comments and README files to explain complex logic.
- Implement error handling and logging to facilitate debugging.
- Write unit tests and integration tests to ensure code reliability.

Follow the guide who express recomens in their documentation: [good express practices](https://expressjs.com/en/advanced/best-practice-performance.html)
